# dialogos

근거 없이는 물러서지 않고 타당한 반론에는 물러서는 한국어 음성 토론 상대를 만듭니다. 그 차이를 잰 기록을 함께 공개합니다.

## 풀려는 문제

AI에게 내 주장을 시험받으려 해도, 몇 번 되받아치면 AI가 근거 없이 물러섭니다. 그래서 내 주장이 버틴 것인지 AI가 져 준 것인지 알 수 없습니다.

## 지금 단계: 판정 실험

토론 상대를 만들기 전에, "덜 물러선다"를 잴 방법부터 만들고 있습니다. 같은 질문과 같은 30턴 대본으로 세 가지 상대를 돌려 두 숫자를 비교합니다.

| 숫자 | 뜻 |
| --- | --- |
| 근거 없는 양보율 | 새 근거 없이 밀기만 한 턴에서 상대가 물러선 비율. 낮을수록 좋습니다 |
| 타당한 반론 수용률 | 전제의 결함을 정확히 짚은 턴에서 상대가 물러선 비율. 높을수록 좋습니다 |

비교하는 상대는 범용 AI 그대로, 지시문만 넣은 상대, 턴마다 "전제가 무너졌는가"를 먼저 판정하는 엔진을 넣은 상대입니다. 엔진이 통과해야 하는 기준 네 가지는 결과를 보기 전에 정해 두었습니다.

- 실험 설계와 통과 기준: [eval/README.md](eval/README.md)
- 채점 기준과 계산 방법: [eval/rubric.md](eval/rubric.md)

실제 모델로 돌린 결과는 아직 없습니다. 지금 저장소에는 질문 20개, 실행기, 엔진 시제품, 채점과 판정 계산, 검사가 들어 있습니다.

## 돌려 보기

Node.js 22.9 이상이 필요합니다. 아래 명령은 모의 모델을 쓰므로 비용이 들지 않습니다. 모의 실행의 숫자는 흐름을 확인하는 용도이고 실험 결과가 아닙니다.

```
npm install
npm test
npm run eval:run -- --provider mock --run try1
npm run eval:label -- --provider mock --run try1
npm run eval:score -- --run try1
```

## 앞으로

1. 질문 20개로 판정 실험을 돌리고 결과표를 공개합니다.
2. 글로 하는 토론에 엔진을 붙입니다.
3. 브라우저의 음성 인식과 음성 합성을 붙여 말로 토론하게 합니다.
4. 사용자의 주장, 근거, 바뀐 입장을 기억해 다음 판에 이어 갑니다.
