# screen: 글로 한 판(화면)

앱을 `npm run app:dev`와 같은 진입점(`app/dev.ts`)으로 빈 포트 둘(`APP_PORT`, `APP_WEB_PORT`)에 띄우고, 창 없는 Chrome으로 사람이 하는 차례대로 한 판을 한다. 사용자가 띄워 둔 개발 서버(8787, 5173)와 그 판 파일(`data/app.sqlite`)은 쓰지 않는다. 모델은 앱의 기본값인 모의 모델이고, 판 파일은 증거 폴더의 새 파일(`app-01.sqlite`)이다. 누르기와 쓰기는 마우스 이벤트와 글자 입력으로 보내고, 단계마다 화면 사진(`shot-NN-*.png`)을 남긴다.

| 단계 id | 사용자 행동 | 보여야 하는 것 |
| --- | --- | --- |
| `app` | 앱을 띄운다 | 화면을 거친 `/api/topics`가 답한다. 두 포트가 8787, 5173이 아니다. 출력은 `cmd-01-app.txt` |
| `topics` | 화면을 연다 | 주제 목록, 모의 모델 안내. 새 판 파일이라 지난 판이 없다 |
| `start` | 첫 주제의 [이 주제로] → 척도의 왼쪽 '대체로' → [이 입장으로 시작] | 고르기 전에는 시작 단추가 눌리지 않는다. 고른 뒤 "지킬 입장: … · 상대: …". 판 화면의 머리가 같은 입장과 상대, "턴 0 / 30". 말은 고른 입장과 상대의 첫 발언 둘 |
| `turn-1`, `turn-2` | 입력 칸에 글을 쳐서 [보내기] (짧은 글 하나, 긴 글 하나) | "턴 n / 30", 보낸 글이 내 말로, 그 뒤에 상대의 답. 입력 칸이 빈다 |
| `reload` | 페이지를 새로 연다 → 지난 판의 [이어 하기] | 지난 판 하나: "2 / 30턴 · 진행 중", "생각: 대체로 내 입장". 이어 연 판의 말들이 새로 고치기 전과 글자까지 같다 |
| `end` | [끝내기] → 사후 입장만 고른다 | "판을 끝냈습니다. 2턴을 주고받았습니다. 두 가지에 답하면 판이 닫힙니다." 입력 칸이 사라진다. 두 문항에 다 답하기 전에는 [기록 남기기]가 눌리지 않는다 |
| `record` | 사후 입장 오른쪽 '대체로', 훈계 문항 '토론' → [기록 남기기] | "생각: 대체로 내 입장 → 대체로 상대 입장 · 이번 판은 토론". 말로 보낸 턴의 줄은 없다 |
| `list` | [목록으로] | 지난 판의 그 판이 "2 / 30턴 · 토론", "생각: 대체로 내 입장 → 대체로 상대 입장", 단추는 [다시 보기] |
| `db` | 판 파일을 읽는다 | `games` 1행(side 0, start_lean -1, end_reason user, end_lean 1, verdict debate, 끝난 때와 기록한 때). `turns` 2행(친 글 그대로, input text, redone 0). 화면의 예외와 console.error 없음 |

## 이 여정이 증명하지 않는 것

- 실제 모델의 답. 모의 모델의 답은 흐름을 확인하려고 만든 문장이다.
- 30턴을 다 써서 끝나는 판, 하루 턴 수와 비용 상한. `app/tests/server.test.ts`, `budget.test.ts`가 맡는다.
- 음성. `voice-screen`이 맡는다.
- Chrome 밖의 브라우저(Safari, Firefox)와 좁은 화면.
